# VibeShot

3D FPS для Windows: одиночная игра с ботами и игра по LAN.

[Скачать VibeShot 0.1.2 для Windows (ZIP, около 340 МБ)](https://github.com/husnetdinovkarim931-stack/-/releases/download/v0.1.2-windows/VibeShot-Windows-v0.1.2.zip)

Распакуйте весь архив и запустите `VibeShot.exe`. Python устанавливать не нужно; папка `_internal` должна оставаться рядом с EXE.

В комнате организатор может нажать «КИК» напротив любого бота. Курсор в меню, комнате и магазине учитывает размер окна и полноэкранный режим.

## Подключение по LAN

1. На компьютере хоста запустите `VibeShot-Allow-LAN.bat` от имени администратора.
2. Запустите игру и выберите «Создать LAN-игру». Сообщите другу показанный IPv4.
3. Друг выбирает «Подключиться по IP» и вводит адрес хоста. `127.0.0.1` на втором компьютере использовать нельзя.
4. Если друг в другой квартире, подключите оба ПК к одной сети Radmin VPN, Hamachi или Tailscale и используйте виртуальный IPv4. Альтернатива — проброс TCP-порта 7777 на роутере хоста.
5. `VibeShot-Check-Connection.bat` проверяет, доступен ли TCP-порт 7777.

Проверено: 113 автоматических тестов и EXE-проверка наведения, кликов, настроек, магазина, кика ботов и запуска матча без ботов.

Журнал: `%LOCALAPPDATA%\VibeShot\game.log`
