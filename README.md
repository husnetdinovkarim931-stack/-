# VibeShot

3D FPS для Windows: одиночная игра с ботами и игра по LAN.

[Скачать VibeShot 0.1.5 для Windows (ZIP, 336 МБ)](https://github.com/husnetdinovkarim931-stack/-/releases/download/v0.1.5-windows/VibeShot-Windows-v0.1.5.zip)

Распакуйте весь архив и запустите `VibeShot.exe`. Папка `_internal` должна оставаться рядом с EXE. Для игры вместе обновитесь оба до версии 0.1.5. Организатор может нажать «КИК» напротив бота.

## Чат в комнате и матче

**T** — открыть чат; **Enter** или «ОТПРАВИТЬ» — отправить сообщение всем участникам и вернуться в игру; **Esc** — закрыть чат с сохранением черновика. Во время ввода персонаж не двигается и не стреляет. Поддерживается русский текст. История сохраняется между комнатой и матчем.

## Подключение по LAN

1. На хосте запустите `VibeShot-Allow-LAN.bat` от имени администратора.
2. Создайте LAN-игру и сообщите другу IPv4 хоста.
3. Друг выбирает «Подключиться по IP» и вводит адрес хоста; `127.0.0.1` на втором компьютере использовать нельзя.
4. Для разных домов подключите оба ПК к одной сети Radmin VPN, Hamachi или Tailscale и используйте VPN IPv4. Через Radmin VPN нужен адрес хоста из Radmin VPN (26.x.x.x).
5. `VibeShot-Check-Connection.bat` проверяет TCP-порт 7777.

Проверено: 114 автоматических тестов и EXE CHAT_UI_PASS / UI_POINTER_PASS.
