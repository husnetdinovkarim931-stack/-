# VibeShot

3D FPS для Windows: одиночная игра с ботами и игра по LAN.

[Скачать VibeShot 0.1.4 для Windows (ZIP, около 340 МБ)](https://github.com/husnetdinovkarim931-stack/-/releases/download/v0.1.4-windows/VibeShot-Windows-v0.1.4.zip)

Распакуйте архив и запустите `VibeShot.exe`. В комнате нажмите **T**, чтобы открыть чат; Enter или «ОТПРАВИТЬ» отправляет сообщение всем участникам. Организатор может нажать «КИК» напротив бота.

## Подключение по LAN

1. На хосте запустите `VibeShot-Allow-LAN.bat` от имени администратора.
2. Создайте LAN-игру и сообщите другу IPv4 хоста.
3. Друг выбирает «Подключиться по IP» и вводит адрес хоста; `127.0.0.1` на втором компьютере использовать нельзя.
4. Для разных домов подключите оба ПК к одной сети Radmin VPN, Hamachi или Tailscale и используйте VPN IPv4.
5. `VibeShot-Check-Connection.bat` проверяет TCP-порт 7777.

Проверено: 114 автоматических тестов, включая передачу сообщений между клиентами, и EXE UI_POINTER_PASS.
