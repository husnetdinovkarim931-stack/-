# VibeShot

3D FPS для Windows: одиночная игра с ботами и игра по LAN.

[Скачать игру для Windows (ZIP, 337 МБ)](https://github.com/husnetdinovkarim931-stack/-/releases/download/v0.1.0-windows/VibeShot-Windows-20261003.zip)

Распакуйте весь архив и запустите VibeShot.exe. Python устанавливать не нужно. Папка _internal и VibeShotServer.exe должны оставаться рядом с игрой.

Для LAN хост выбирает «Создать LAN-игру», друг — «Подключиться по IP» и вводит адрес хоста. Для разных сетей нужна общая виртуальная локальная сеть или настроенный доступ к серверу.

Состояние проверки: меню запускается. На компьютере сборки Windows заблокировала встроенный сервер ошибкой 4551; запуск офлайн-матча и LAN в EXE пока не подтверждён.

Журнал: %LOCALAPPDATA%\VibeShot\game.log
