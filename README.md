# VibeShot

3D FPS для Windows: одиночная игра с ботами и игра по LAN.

[Скачать последнюю версию для Windows (ZIP, 336 МБ)](https://github.com/husnetdinovkarim931-stack/-/releases/download/v0.1.1-windows/VibeShot-Windows-v0.1.1.zip)

Распакуйте весь архив и запустите VibeShot.exe. Python устанавливать не нужно. Папка _internal должна оставаться рядом с игрой.

В комнате организатор может нажать «КИК» напротив любого бота. Удалённые боты не возвращаются автоматически. Курсор в меню, комнате и магазине учитывает текущий размер окна и полноэкранный режим.

Для LAN хост выбирает «Создать LAN-игру», друг — «Подключиться по IP» и вводит адрес хоста.

Проверено: 113 автоматических тестов и EXE-проверка наведения, кликов, настроек, магазина, кика ботов и запуска матча без ботов.

Журнал: %LOCALAPPDATA%\VibeShot\game.log
